# 🚀 PenRX+ (بن آر إكس +)
### المنظومة الطبية الشاملة والذكية لكتابة الروشتات وإدارة العيادات الطبية

**الإصدار الحالي / Current version:** `1.61.0` (المصدر الوحيد للحقيقة: `package.json`)

---

## 🌟 نظرة عامة
تم بناء **PenRX+** من الصفر لتقديم تجربة فائقة السرعة، بتصميم حديث ونظيف جداً وغير مزدحم، ليعمل بتناغم تام عبر:
1. **تطبيق هاتف أندرويد حقيقي (Android APK)** قابل للتثبيت المباشر.
2. **برنامج كمبيوتر حقيقي (Electron Desktop App)** بصيغة تثبيت `.exe` لنظام ويندوز مع اختصار سطح المكتب.
3. **دعم هواتف الآيفون (iOS)** عبر تقنية PWA الفائقة مع تثبيت الأيقونة على الشاشة الرئيسية بضغطة زر.
4. **منظومة موحدة وقاعدة بيانات سحابية (Supabase PostgreSQL)**:
   - يدخل الطبيب من الهاتف أو الكمبيوتر ليجد نفس الحساب، الروشتات، وبيانات المرضى فوراً.

## ⚡ محرك البحث الدوائي العالمي (SuperEngine 0.2ms)
يمثل محرك البحث في **PenRX+** نقلة نوعية تختلف عن أي برنامج آخر:
- **حجم البنك الدوائي المدمج (الرقم الفعلي):** **43,713 صنفًا ومستحضرًا** (`src/data/comprehensive-drugs.json` = 43,500 + `src/data/extended-specialty-drugs.json` = 213)، ويتوسّع سحابياً بإضافات الأطباء الموثّقة.
- **فائق السرعة (Sub-Millisecond < 0.5ms)**: يبحث بمجرد كتابة أول حرف أو حرفين بدون أي تأخير.
- **ثنائي اللغة بالكامل (عربي / إنجليزي)**: يبحث بالاسم التجاري (Brand Name) أو المادة الفعالة (Active Ingredient) أو الشكل الدوائي أو الشركة المنتجة.
- **تطابق مرن وتصحيح الأخطاء الإملائية (Fuzzy & Synonym Matching)**.
- **الذكاء الاصطناعي (AI Drug Synthesis)**: في حال كتابة دواء جديد غير مدرج، يحلل الذكاء الاصطناعي طبيعة الدواء ويقترح المادة الفعالة والشكل والجرعة النموذجية.
- **التعلم المجتمعي ومشاركة الأدوية (Crowdsourced Cloud Database)**:
  - عند إدخال طبيب لدواء جديد وحفظه، يتم حفظه فوراً في قاعدة البيانات السحابية، ليصبح مقترحاً تلقائياً وسريعاً لجميع الأطباء الآخرين!

## 📑 الصفحات والأقسام الرئيسية
1. **لوحة التحكم (Dashboard)**:
   - إحصائيات يومية، روشتات اليوم، إجمالي المرضى، ترخيص النظام، وأحدث الروشتات مع زر إرسال واتساب مباشر.
2. **كتابة الروشتات (Prescription Writer)**:
   - واجهة هادئة وبسيطة بدون أي ازدحام.
   - إكمال تلقائي لبيانات المريض وتنبيهات الحساسية الطبية (Allergies).
   - محرك البحث الفوري مع تخصيص الجرعات، التكرار، والمدة.
   - معاينة حية وترويسة طبية راقية مع كود QR.
   - طباعة فورية ومشاركة مباشرة لرقم واتساب المريض بنقرة واحدة.
3. **سجل الروشتات والمرضى (History & Patients)**:
   - بحث شامل باسم المريض، رقم الهاتف، أو رقم الروشتة، مع إمكانية إعادة الإصدار والطباعة.
4. **الفروع والعيادات (Clinics & Branches)**:
   - إدارة فروع المراكز، العناوين، مواعيد العمل، وأرقام الحجز.
5. **الإعدادات العامة (Settings & Biometrics)**:
   - بيانات الطبيب، درجاته العلمية، التخصص، وترخيص النقابة.
   - تفعيل الدخول ببصمة الإصبع (Biometric Fingerprint).
   - معرّف الجهاز (Hardware Machine ID).
6. **الاشتراكات والجدار الأمني (Subscriptions)**:
   - حائط حماية أمني كامل للبرنامج.
   - نفس الباقات الحالية (تجريبي مجاناً 30 يوم، شهري 150 ج.م، 3 شهور 400 ج.م، 6 شهور 800 ج.م، وسنوي VIP بـ 1500 ج.م).
   - وسائل الدفع المعتمدة: **فودافون كاش** و**إنستا باي** على الرقم: `01094085228`.
   - بمجرد موافقة الإدارة يفتح البرنامج تلقائياً بفضل المزامنة اللحظية (Polling Sync).

## 👑 بورتال المالك المستقل (Owner Admin Portal)
- رابط البورتال معزول تماماً ومحمي برمز دخول سري: `/admin/portal`.
- لوحة تحكم بإجمالي الطلبات، المفعلة، المجانية، وإجمالي الإيرادات.
- تفعيل مباشر بنقرة زر واحدة بنفس مدة الباقة.
- أداة زيادة أو خفض الأيام (+5، +30، +90، +سنة).
- ربط أكثر من جهاز لنفس الطبيب بنفس الاشتراك (Multi-Device Binding).

## 🚀 تشغيل وبناء التطبيق

### 🌟 مركز التحكم الشامل التفاعلي (Master Control):
يمكنك فتح مركز التحكم التفاعلي الموحد بنقرة واحدة لاختيار أي عملية تشغيل أو بناء أو إصدار:
```bash
bat\PenRX-Master-Control.bat
```

### 1. تشغيل نسخة الويب محلياً:
```bash
bat\Start-PenRX-Web.bat
# أو
npm run dev
```

### 2. تشغيل نسخة الكمبيوتر (Electron Desktop):
```bash
bat\Start-PenRX-Desktop.bat
# أو
npm run electron:dev
```

### 3. فتح بورتال الإدارة السحابي (Admin Portal):
```bash
bat\Start-Admin-Portal.bat
```

### 4. بناء ملف التثبيت لويندوز (.exe):
```bash
bat\Build-Electron-Installer.bat
# أو
npm run electron:build
```
سيكون ملف التثبيت متاحاً في مجلد `dist-electron/` ومجلد `releases/`.

### 5. بناء تطبيق الأندرويد المحلي (APK):
```bash
bat\Build-Android-APK.bat
# أو فتح المشروع في أندرويد ستوديو:
bat\Open-Android-Studio.bat
```

### 6. إطلاق ونشر إصدار شامل سحابياً (Release Manager):
```bash
bat\Release-New-Version.bat
```

### 7. بناء تطبيق الأندرويد (APK) وبرنامج الكمبيوتر عبر GitHub:
تم تجهيز ملف الأتمتة الكامل:
`.github/workflows/build-and-release.yml`
بمجرد رفع الكود على مستودع GitHub وعمل Release جديد:
1. يقوم سيرفر GitHub ببناء تطبيق الأندرويد الحقيقي `PenRX+.apk`.
2. يقوم سيرفر GitHub ببناء برنامج الويندوز الحقيقي `PenRX+-Setup.exe`.
3. يتيح لك روابط التحميل المباشرة الفورية على صفحة الـ Releases لتوزيعها وتسويقها.

### 5. لهواتف الآيفون (iOS):
- افتح الموقع من متصفح Safari على الآيفون.
- اضغط على زر المشاركة (Share).
- اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
- سيتم تثبيت PenRX+ كتطبيق أصلي بأيقونته وشاشته الكاملة بدون شريط المتصفح وبسرعة فائقة.
